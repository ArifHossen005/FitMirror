Also worth knowing before you start: this session caught and fixed two
more real, systemic bugs the same way Decision D-13's original two were
found — by actually running the code, not by inspection:
  1. `TENANT_DISK_DRIVER=` ships as a present-but-empty string in .env,
     not absent — env()'s default only applies when a key is *missing*,
     not blank. The `tenant` disk (S3/R2 in prod, local in dev) silently
     had no driver since Phase 1.A/2.A; nothing had ever actually written
     to it in a test until this session's PDF generation did. Fixed in
     config/filesystems.php with `env(...) ?: (...)`.
  2. A queued job (SendInvoiceEmailJob) eager-loading `$invoice->tenant->
     owner` resolved to null on every real queue worker, because User
     carries TenantScope and a queued job has no ambient TenantContext —
     the exact class of bug D-13 describes, this time in a job. Any new
     job or Mailable that reaches through a Tenant to a User (or another
     BelongsToTenant model) must use `User::withoutTenantScope()->find(...)`
     explicitly, never the bare relation.
